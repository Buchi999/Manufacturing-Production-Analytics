# Manufacturing-Production-Analytics

A Python data analysis project examining one year (2025) of production data from Prime Manufacturing Ltd., a household electrical appliance manufacturer operating multiple factories, production lines, machines, and shifts.

**Prepared by:** Onyebuchi Uremeh

## Business Scenario

Prime Manufacturing Ltd. manufactures household electrical appliances across multiple factories and production lines. The company has experienced steady growth, but management has identified inconsistencies in production output, increasing machine downtime, varying product quality, and rising operational costs. This project analyzes the production dataset and presents findings to support operational decision-making and continuous improvement.

## Dataset

The dataset contains production activity records with the following fields:

- Production ID, Production Date, Factory, Production Line, Shift
- Machine ID, Machine Type, Operator ID
- Product Category
- Planned Production, Actual Production, Defective Units
- Downtime (Minutes), Production Hours
- Energy Consumption (kWh)
- Maintenance Cost ($), Unit Production Cost ($)
- Temperature (°C), Humidity (%)
- Quality Inspection Score

## Project Workflow

The analysis in the notebook is organized into the following tasks:

### Task 1 – Data Exploration
Initial review of dataset structure, data types, missing values, duplicate rows, cardinality, and summary statistics.

### Task 2 – Data Cleaning
- Removed duplicate records
- Fixed data types
- Handled missing values (numeric and categorical columns)
- Dropped rows missing critical identifiers
- Standardized inconsistent text entries
- Corrected invalid values (e.g., negative figures, defective units exceeding actual production)
- Validated logical ranges (humidity, quality inspection score, temperature)
- Handled outliers in continuous variables
- Exported the cleaned dataset

### Task 3 – Exploratory Data Analysis
Covered production performance, factory performance, production line performance, machine performance, product quality, operational efficiency, downtime, energy consumption, maintenance, workforce (operator) performance, and correlation across numeric variables.

### Task 4 – Grouping and Aggregation
- Multi-level grouping (Factory × Production Line)
- Shift-based comparison across factories
- Product category performance by factory
- Machine type performance across factories
- Monthly time-based trends
- Pivot table of efficiency by factory vs. shift
- Cost-efficiency ranking combining cost, quality, and output
- Identification of best/worst performing combinations

### Task 5 – Data Visualization
- Production efficiency by factory
- Defect rate by production line
- Machine downtime distribution
- Quality inspection score by product category
- Energy consumption vs. actual production
- Maintenance cost vs. downtime
- Monthly production trend
- Heatmaps: efficiency by factory vs. shift; defect rate by product category vs. factory; correlation across numeric variables
- Operator performance (top vs. bottom)

### Task 6 – Management Report
A professional report summarizing findings, concerns, opportunities for improvement, and data-backed recommendations for management.
